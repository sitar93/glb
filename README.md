# Free Eurorack 3D CAD Library

**75 accurate hardware parts for Eurorack design.**  
Available as **GLB** and **STEP** files.

This free library contains 75 accurate 3D models of the hardware components we use in our own Eurorack module designs at **Jolin**.

The collection includes interactive **GLB** files for web visualization and **STEP** files for CAD software, making it easy to plan panel layouts, verify clearances, and integrate real-world components into your projects.

Each model is based on a real component, providing reliable references for DIY builders, hardware designers, and Eurorack manufacturers.

## Included Categories

- Jacks  
  - Thonkiconn
  - PJ301BM
  - PJ301CM
  - PJ366ST

- Potentiometers  
  - Alpha RV09
  - RD901F
  - RD902F
  - RV112FF

- Knobs  
  - Rogan
  - Davies
  - T18
  - Micro

- Switches  
  - Toggle switches
  - Push switches
  - Slide switches
  - Latching switches

- Faders
- LEDs
- Headers and connectors
- JST, IDC, and Eurorack power cables
- Standoffs and spacers
- Screws, nuts, washers, and rivets
- Vactrols and optocouplers
- Panel hardware and assembly accessories
